Account recovery

Forgot your PIN?

Enter the phone number on your account. If it has a verified email address, we’ll send a secure reset link.

Choose a new PIN

Reset your PIN

Create exactly four numeric digits. Resetting your PIN signs your account out on other devices.

Use an account backup code

Enter a saved account backup code, not an authenticator recovery code. Resetting revokes every code in the set.

Use a support recovery code

Only use a one-use code given by NDAHI support after an identity check. Authenticator settings stay attached to the account.

No saved recovery method? Contact support for an identity check. A payment number or voucher screenshot alone does not prove ownership.
